## 方块与物品

| 方块 | 说明 |
|------|------|
| 矿物转换器 | 按地图矿点稀有度，把可开采的矿物相互转化 |
| 物品传输中枢 | 零缓冲物流网络：按需拉取、盈余自动推送至核心，可跨中枢级联 |
| 电力保护器 | 电网崩溃时锁定电量并进入保护，记录消耗电力后在恢复模式下逐步偿还 |
| 利滚利发电机 | 按已存电力的 1%/秒复合产出电力，产出随电网状态自适应 |
| 发电泵 | 抽水同时消耗水发电 |
| 两用交叉器 | 传送带 / 导管两用的交叉路口 |
| 两用仓储 | 3×3 仓储与合成一体，配套液体行为 |
| 万向交叉器 | 1×1 物品交叉器：全局设置输出优先级应用到所有输入方向，可按方向单独覆盖；内置模板一键应用（均分/全右/主右备左/上下直通）、可手动保存自定义模板（0~4，数值越大越优先，同优先级轮流均分，0 不输出），50 物品/秒，点击方块在配置面板中直接设置 |
| 信号源 | 放置后注册唯一信号（4 个字母或数字，绑定队伍），半径 15 格广播，强度随距离**对数衰减**（0~99，σ=3 格），按住 H 键查看覆盖 |
| 信号中继器 | 每 tick 实时判定：绑定编号的信号可用度（SINR，阈值 3.3/99）或同编码卫星强度达标才转发，自身提供同样半径 15 格的信号并可级联；干扰器或同信道异编码源可把链路压断，配置面板状态行实时显示入站地面/卫星强度与未转发原因 |
| 卫星发射中枢 | 生产待发射卫星（消耗石油与缓冲电力 10000），生产完成登记后等待控制台发射 |
| 卫星控制台 | 发射卫星：绑定信号后指派轨道（LEO / MEO / GEO / SSO），按轨道扣燃油；与发射中枢 1:1 配对 |
| 开关 | 控制指向方块的启用/禁用 |
| 电力源 | 沙盒无限电源（与电网内其他电力源平分产出） |

## 功能

- **方块搜索**：建造菜单内跨全分类搜索方块，支持中文拼音模糊匹配（全拼/首字母）、搜索历史记录；
- **多人暂停**：多人游戏中可申请暂停，支持关闭/仅管理员/自定义白名单三种模式；
- **信号覆盖显示**：按住 H 键（或设置切换为按一下切换）查看信号强度——范围模式逐格显示最强信号（地面信号源与在轨卫星同一模型、同一透明度公式与强度标度），视野窄时逐格显示强度数字，淡入淡出过渡，数字/范围透明度可调；
- **自动更新**：主界面自动检测 GitHub 新版本并弹窗提示，支持游戏内下载安装到模组目录后一键重启。

## 卫星系统（第一阶段）

卫星是**真实实体单位**（机型按轨道划分：LEO / MEO / GEO / SSO），沿**星下点扫描轨迹**飞行（不是圆轨道）：LEO/MEO 东西向匀速回绕 + 南北正弦摆动，SSO 对偶（南北回绕 + 东西摆动 = 极轨），GEO 定点悬停——轨道用于划分不同卫星的功能，且轨道越高越难被地面击中（影响未来拦截难度）：

| 轨道 | 燃油（石油） | 轨迹形态 | 覆盖半径（随图幅等比缩放，下为 250×250 基准） | 扫描周期 |
|------|------------|---------|---------|------|
| LEO | 1000 | 东西回绕 + 南北正弦摆动 | 0.32×短半轴 = 40 格 | 90s |
| MEO | 2500 | 同 LEO | 0.48×短半轴 = 60 格 | 150s |
| GEO | 5000 | **定点悬停**（与时间无关） | 整图（图心到最远角点 + 5% 短半轴） | 无 |
| SSO | 8000 | 南北回绕 + 东西摆动（极轨） | 0.20×短半轴 = 25 格 | 70s |

- **测试卫星**：与信号卫星效果完全相同，仅需 1 硅、1 秒生产，可发射至任意轨道（信号卫星限 LEO/MEO/GEO，SSO 不对信号卫星开放）——用于验证发射链路或廉价快速叠星；**仅在沙盒模式可用**，其他模式不出现（中枢不显示该选项、不生产，发射请求被权威端拒绝）；
- **覆盖与强度**：卫星为其所属编码提供星下点覆盖圆；轨道越高覆盖越大、强度越低——覆盖半径随**图幅短半轴**等比缩放（比例 LEO 0.32 / MEO 0.48 / SSO 0.20，250×250 基准即 40 / 60 / 25 格；GEO 为**定点整图**：半径 = 图心到最远角点 + 5% 短半轴的定点环偏移），每星强度 LEO 9.9 / MEO 8.58 / GEO 7.26（与地面同一 0~99 标度），干扰按信噪比（SINR）折算成质量因子后，多星按**非相干功率合成 √(Σeᵢ²)** 叠加（N 颗同强度 = √N 倍，净空 LEO 单星有效 7.92、2 星 11.20、3 星 13.72、4 星 15.84、10 星 25.05）；单星即可激活中继器转发（阈值 >3.3），叠星按 √N 提升抗干扰裕度；**约 10 颗卫星覆盖全图，且任意图幅下均成立**（10 颗 GEO 均布时任意时刻联合覆盖约 98%，角落由扫描轨迹周期性覆盖；极端长宽比地图长轴方向按比例增星）；
- **扫描几何**：正弦轴按该轨道的**覆盖半径内缩**（覆盖圆尽量落在图内）；回绕进出场有 6% 圈长的**淡入淡出**（卫星本体与信号强度同步升降，消除回绕瞬间的"瞬移"观感）；正弦相位按黄金比×0.1 失谐推进，每圈错开约 22°，约 16 圈后轨迹族铺满全图（含四角），单颗 LEO 扫遍全图约 24 分钟；
- **干扰**：同信道干扰器可局部压制卫星的覆盖与绑定（压制格在 H 键覆盖中不显示）；
- **远方指派**：卫星覆盖可解锁地面信号范围外的控制台绑定，但中枢/控制台 1:1 配对仍只统计地面覆盖；
- **不可操控 / 不可攻击**：玩家与逻辑处理器均无法操控，不会被任何单位索敌、伤害或碰撞（含其他卫星与空中单位），小地图不显示过境；
- **持久化**：卫星随存档保存，轨道相位续接不跳位；名册（编码/信道/轨道/相位）由卫星控制台存档块代存，任一存活控制台即可恢复，控制台全毁则卫星退化为未绑定（仅覆盖强度，不参与绑定）；
- **预留**：卫星血量 400，目前只能被脚本化伤害击落——ASAT 拦截手段在后续阶段接入。

## 构建与固化验证

依赖 Mindustry `v160.5` 的 jar 与 **JDK 17**（Android 端 d8 需要）：

```powershell
# 一条龙：30 项代码锚点检查 → 编译 deploy → 自动同步游戏模组目录
powershell -ExecutionPolicy Bypass -File scripts\hub-deep-check.ps1

# 仅桌面快速构建
.\gradlew.bat jar
```

安装：把构建出的 `Silicon.jar` 放入游戏的 `mods` 目录（客户端：`%APPDATA%/Mindustry/mods`）后启动游戏。

## 开发流程（固化）

1. 修改代码后先跑单元测试（`tests/` 下三个套件，javac 直接编译运行，不依赖 Mindustry 运行时）
2. 运行 `scripts/hub-deep-check.ps1`：任一锚点 FAIL 即阻断；通过则自动 deploy 并把最新 jar 同步到 `%APPDATA%\Mindustry\mods\Silicon.jar`
3. 重启游戏实测
4. 版本号按 AGENTS.md 规范 bump，commit 格式 `[版本] 类型: 描述`
