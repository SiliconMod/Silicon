# Silicon

> 又称"更好的像素工厂"（
>
> 你是否被左脚踩右脚的矿物开采气晕？你是否试过电力归零无法启动的绝望？
>
> 使用硅，解决以上问题！——锐意更新中

一个添加了个人创意的 Mindustry 模组（`v159.7+`），提供多种实用方块与便捷功能。

## 方块与物品

| 方块 | 说明 |
|------|------|
| 矿物转换器 | 按地图矿点稀有度，把可开采的矿物相互转化 |
| 物品传输中枢 | 零缓冲物流网络：按需拉取、盈余自动推送至核心，可跨中枢级联 |
| 电力保护器 | 电网崩溃时锁定电量并进入保护，记录消耗电力后在恢复模式下逐步偿还 |
| 利滚利发电机 | 按已存电力的 1%/秒复合产出电力，产出随电网状态自适应 |
| 发电泵 | 抽水同时消耗水发电 |
| 两用交叉器 | 传送带 / 导管两用的交叉路口 |
| 万向交叉器 | 1×1 物品交叉器：全局设置输出优先级应用到所有输入方向，可按方向单独覆盖；内置模板一键应用（均分/全右/主右备左/上下直通）、可手动保存自定义模板（0~4，数值越大越优先，同优先级轮流均分，0 不输出），50 物品/秒，点击方块在配置面板中直接设置 |
| 开关 | 控制指向方块的启用/禁用 |
| 电力源 | 沙盒无限电源（与电网内其他电力源平分产出） |

## 功能

- **方块搜索**：建造菜单内跨全分类搜索方块，支持中文拼音模糊匹配（全拼/首字母）、搜索历史记录；
- **多人暂停**：多人游戏中可申请暂停，支持关闭/仅管理员/自定义白名单三种模式。

## 设置

进入游戏后：`设置 → Silicon设置`。

| 设置 | 说明 |
|------|------|
| 显示搜索历史 | 是否在方块搜索栏中显示最近搜索（可游戏内即时开关） |
| 选择后清除输入 | 从搜索结果选择方块后是否清空搜索输入 |
| 暂停模式 | 多人暂停权限：关闭 / 仅管理员 / 自定义（聊天命令 `!pause grant <玩家名>`） |
| 暂停请求 | 启用后按下暂停键向服务器发送暂停申请 |
| 管理暂停白名单 | 打开自定义暂停模式的白名单管理对话框 |

## 构建

依赖 Mindustry `v159.7` 的 jar（编译 classpath）：

```powershell
# Windows（需要 JDK 17+）
powershell -ExecutionPolicy Bypass -File build-mods.ps1
# 产物输出到 ./new/ 目录
```

或使用 Gradle：

```bash
./gradlew jar
```

安装：把构建出的 `Silicon.jar` 放入游戏的 `mods` 目录（客户端：`%APPDATA%/Mindustry/mods`）后启动游戏。
