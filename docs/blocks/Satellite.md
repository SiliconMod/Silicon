# 卫星系统模型（a0.13.0.0 · 扫描轨迹 + 星下点覆盖）

> 本文描述**在轨卫星的运动与覆盖几何**。信号侧的强度合成（SINR / 叠星 / 干扰）见 [Signal.md](Signal.md)；
> 发射链路（中枢生产 → 控制台发射 → 扣油与缓冲电力）见 [README 卫星章节](../../README.md)。

## 1. 一句话

卫星是**真实引擎单位**（`mindustry.gen.UnitEntity`），运动由 `OrbitSatelliteController` 每帧驱动；
**位置 = 存档相位的纯函数**（相位本身是自累加字段），所以任何读档/重启都精确续接，不依赖 `Time.time`。

## 2. 轨迹（不是圆轨道）

几何锚点 `half = min(图宽, 图高) / 2`（世界像素；无地图时回退 1000px）。设进度 `u = 相位`：

| 轨道 | 星下点 X | 星下点 Y | 周期 | 语义 |
|------|---------|---------|------|------|
| **LEO** | `frac(u) · 图宽`（东西向**匀速回绕**：从一侧离场、另一侧进场） | `高/2 + amp·sin(2π(1+δ)u)`（南北**正弦摆动**） | 90s | 低轨扫描 |
| **MEO** | 同 LEO | 同 LEO（`amp` 不同） | 150s | 中轨扫描 |
| **SSO** | `宽/2 + amp·sin(2π(1+δ)u)`（东西摆动） | `frac(u) · 图高`（南北**匀速回绕**） | 70s | **极轨**（太阳同步语义） |
| **GEO** | `图心X + cos(方位角)·r₀` | `图心Y + sin(方位角)·r₀` | 定点 | **真·定点**（与时间无关） |

- `amp = 主轴长度/2 − scanInset(轨道)`：**正弦轴按该轨道的覆盖半径内缩**（`scanInset = clamp(覆盖半径, 0, 0.8·half)`，
  下限 `SCAN_MARGIN = 8px`），让覆盖圆尽量落在图内——旧实现固定内缩 8px，贴边时大半个圆跑到图外。
- `r₀ = 0.05 · half`：GEO 的定点环偏移（方位角 = 发射时中枢相对图心的方向；多颗 GEO 自然散开）。
- `δ = SCAN_DRIFT = 0.0618034`（黄金比 × 0.1）：正弦相位按 `(1+δ)` 失谐推进，**每圈错开 2πδ ≈ 22.2°**，
  轨迹族约 `1/δ ≈ 16.2` 圈后铺满全图（含圆轨道永远扫不到的四个角），且永不严格重复。
  换算：单颗 LEO 扫遍全图约 24 分钟，MEO 约 40 分钟，SSO 约 19 分钟。
- 朝向 `rotation` = 轨迹的解析导数方向（纯装饰，不影响任何判定）。

### 2.1 回绕淡入淡出

回绕轴在 `u` 的整数边界处会"另一边进场"，因此引入**存在度**：

```
presence(orbit, u) = clamp(frac(u) / FADE, 0, 1)                , frac(u) < FADE
                   = clamp((1 − frac(u)) / FADE, 0, 1)          , frac(u) > 1 − FADE
                   = 1                                          , 其余
FADE = WRAP_FADE = 0.06（圈长比例）；GEO 恒为 1
```

存在度同时作用于**两处**，保证观感与判定一致：

1. `SatelliteUnits.draw()` 的绘制透明度（贴图与程序化兜底造型都吃这个系数）；
2. `SatelliteManager.satelliteRawAt()` 的原始强度 → 覆盖显示、SINR 判定、中继激活同步升降
   （不会出现"图已经淡出了但信号还在"）。

## 3. 覆盖与强度

- **覆盖半径**（世界像素，随图幅短半轴等比缩放）：LEO `0.32·half`、MEO `0.48·half`、SSO `0.20·half`
  （250×250 图 = 40 / 60 / 25 格）；**GEO = 整图**：`√((宽/2)² + (高/2)²) + 0.05·half`（图心到最远角点 + 定点环偏移）。
- **单星瞬时覆盖率**（250×250）：LEO ≈ 8.0%、MEO ≈ 18.1%、SSO ≈ 3.1%、GEO = 100%。
- **原始强度**（0~99 标度，覆盖圆内为定值 × 存在度）：LEO/SSO 9.9、MEO 8.58、GEO 7.26。
- **有效强度**：`raw × SINR 质量因子`（底噪 `NOISE_FLOOR = 3.3`、`SINR_REF = 3.5`），
  再按 `√(Σeᵢ²)` 做**非相干功率合成**——净空单星有效 LEO 7.92 / MEO 5.49 / GEO 3.48，
  均超过中继器激活阈值 3.3。详见 [Signal.md](Signal.md) §3。
- **上行门控**：该编码的地面源全部消失 → 卫星停止广播（`SignalChannel.hasLiveSource`），重放同编码源自动恢复。

## 4. 发射与名册

- 发射时相位就地确定：**GEO** = 中枢相对图心的方位角；**其余** = 在 96 个采样相位里取「星下点距中枢最近」的那个
  （卫星出生即落在中枢附近的轨道点上，衔接发射特效，不会先停在方块上）。
- 名册 `SatelliteRecord{unitId, code, channel, orbit, phase}` 是卫星语义的唯一载体；名册由**卫星控制台存档块**代存
  （单位无自定义实体组件），任一存活控制台即可恢复，控制台全毁则卫星退化为未绑定（仅覆盖，不参与绑定）。
- 名册缺失时的兜底：控制器本帧悬停并触发 `reconcileMissing()`；对账会**从单位当前位置反推相位**
  （GEO 用 `atan2`、SSO 用 `y/图高`、LEO/MEO 用 `x/图宽`）。
- 相位语义变更说明：旧档存的是"叠加了 `Time.time` 的旧语义 u"，读入后按新语义继续推进——
  位置连续，只是与旧档保存瞬间的位置不同（一次性差异，之后完全确定）。

## 5. 视觉

- 贴图：`assets/sprites/units/satellite-{leo,meo,geo,sso}.png`（48×48 = 12 世界单位；本体 + 两侧太阳能板，
  四型按轨道区分轮廓与轨道色）。`SatelliteUnits.load()` 会先试内容名（`silicon-satellite-leo`）再试去前缀名
  （`satellite-leo`），两种命名都能命中；**都没有时** `draw()` 回落到程序化造型（队色环 + 核心 + 太阳能板线 + 遥测闪烁），
  所以缺贴图不会出现 error 白方块。贴图本身不含队伍信息，绘制时在中心补一个队色点。
- `hitSize = 24` 只为**悬停信息面板触发窗**（`5 + hitSize/2`）；造型尺寸与之解耦，保持"小卫星"观感。
- 卫星不显示在小地图（`drawMinimap = false`），不被索敌/伤害/碰撞（`targetable/hittable/physics = false`），
  不占队伍单位上限（`useUnitCap = false`），并对全部状态效果免疫。
- 环境旗标 `envEnabled = Env.any` / `envDisabled = Env.none`：否则焦土图（Erekir）与太空图会被引擎「环境处死」
  （该路径不看 hittable/targetable，表现为发射后一帧消失）。

## 6. 常量速查（`SatelliteManager`）

| 常量 | 值 | 作用 |
|------|----|------|
| `SCAN_DRIFT` | 0.0618034 | 正弦相位失谐比（黄金比×0.1） |
| `SCAN_MARGIN` | 8px | 正弦轴内缩下限（图幅很小时防止压成一条线） |
| `WRAP_FADE` | 0.06 | 回绕进出场淡入淡出占圈长比例 |
| `orbitPeriod(orbit)` | LEO 90s / MEO 150s / SSO 70s | 一圈时长；GEO 返回 1（占位，不使用） |
| `coverageRadius(orbit)` | 见 §3 | 星下点覆盖半径 |
| `satelliteStrength(orbit)` | 9.9 / 8.58 / 7.26 | 覆盖圆内原始强度 |
