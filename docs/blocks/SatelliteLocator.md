# 卫星定位器（Satellite Locator）

> 它给[反卫星拦截塔](AsatInterceptor.md)提供目标。塔的机制与平衡见那一篇。

## 1. 一句话

2×2 探测设施：发现 **80 格**内的敌方在轨卫星，把结果发布到**绑定的信号编码**——
拦截塔绑定同一编码即可收到（N:N：多个定位器可绑同一编码、结果合并，同一编码可被多座塔读取）。

## 2. 它不发射信号

信号编码是**信号源**的东西：只有信号源能发射信号，也只有信号源的信号参与信道、干扰、中继、
频谱那一整套系统。定位器只是一台**探测器**，它的产物是"情报"，不是"信号"：

| | 信号源 | 卫星定位器 |
|---|---|---|
| 产物 | 信号（带编码、信道、强度衰减） | 定位情报（敌星实体 + 时间戳） |
| 传播 | 半径 15 格广播 + 中继器转发，可被干扰 | 直接给本队所有拦截塔（不经过空间） |
| 需要配对 | 需要（塔/中继/控制台按编码绑定） | **需要**（与拦截塔共用同一信号编码） |
| 会被干扰 | 会（同信道干扰器压制） | 不会被干扰（但断电即失效） |

## 3. 为什么需要它

拦截塔打得远（80 格），但**看不见**天上的东西：卫星单位 `targetable = false`，引擎索敌看不到它；
`hittable = false`，常规伤害路径也碰不到它。所以塔的目标不能来自"天上所有的敌星"，
只能来自这份外部情报。

这也把"打卫星"从火力问题变成了**信息问题**：

| 想让拦截生效，必须凑齐 | 缺了会怎样 |
|---|---|
| 一座工作中的定位器（本队任意数量，效果相同） | 塔没有目标来源，只能空转 |
| 目标在塔的 80 格射程内 | 情报里有目标，但超出射程，继续等它飞近 |
| 塔所在位置的**信号可用度**够高 | 锁定很慢（见塔的文档） |
| 电网电池里攒够 10000 电力 | 打不出这一发 |

## 4. 参数

| 项 | 值 | 说明 |
|---|---|---|
| 探测范围 | **80 格** | 只上报自己周围 80 格内的在轨卫星，与拦截塔射程一致（探得到就打得到） |
| 刷新 | 10 tick 一次 | 卫星移动快，但不必每 tick 重扫整个单位表 |
| 情报有效期 | **180 tick = 3 秒** | 超过即过期（`SatelliteIntel.STALE_TICKS`） |
| 耗电 | **2000/秒** | 断电、被逻辑门关闭即停止上报 |
| 建造成本 | 铜 800 · 铅 600 · 硅 700 · 钛 450 · 钍 250 · 塑钢 150 · 中空玻璃 200 | 血量 900 |
| 面板 | 显示"已定位 N 颗敌星 / 上报开或关 / 链路状态"，并有一个"停止上报"按钮 | 关掉它，本队拦截塔 3 秒内失去目标 |

## 5. 面板（配置项都在这里）

定位器的面板是这套设施里**唯一**的可配置处：

- **状态行**：当前定位到几颗敌星、上报是开还是关；
- **链路行**：有电时为"情报链路正常：本队拦截塔可见"，无电时红字警示；
- **按钮**：停止/开始上报（临时关掉侦测，或用来验证"塔失去目标后是否真的待机"）。

拦截塔的面板保留，但只读：它显示情报数量、当前锁定用时、电量是否够一发——
不再需要玩家做任何配对。

## 6. 失效路径

情报按队伍发布、按时间戳判过期，因此：

- 定位器**断电 / 被逻辑门关闭 / 停止上报** → 立即撤稿 → 3 秒内塔失去目标；
- 定位器**被拆** → `onRemoved` 清；换队 → `changeTeam` 清；读档/换图 → `SatelliteManager.reset()` 整体清空；
- **范围内没有敌星** → 发布空快照（塔同样没有目标，面板显示"0 个目标"）。

## 7. 沙盒自测

沙盒模式下定位器会连同**己方**卫星一起探测（判据为"当前处于沙盒模式"），
好让整条链路能在单机里跑通：发一颗 → 放定位器 → 放拦截塔 → 看它锁定并击落。
正式模式不含这段放宽——那里只探测敌方卫星。

## 8. 常量速查

| 常量 | 值 |
|---|---|
| `refreshInterval` | 10（tick） |
| `SatelliteIntel.STALE_TICKS` | 180（tick，= 3 秒） |
| `SatelliteIntel.MAX_ENTRIES` | 64 |
| 耗电 | 2000/秒 |
