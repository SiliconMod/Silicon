# 近地轨道离子炮（LOIC · Low Orbit Ion Cannon）

> 它是第三种卫星类型（`SatelliteLauncher.TYPE_ION`），发射链路见 [Satellite.md](Satellite.md) §4，
> 反制它的手段见 [AsatInterceptor.md](AsatInterceptor.md)。

## 1. 一句话

2×2 级的对地武器卫星：**只能发到 LEO**（"近地"即约束），充能 60 秒后可下达一次打击，
由卫星在自己**星下点的覆盖范围内**选最近的敌方建筑落下 3000 中心伤害。

## 2. 为什么是"命令"而不是"手动瞄准"

卫星在第一阶段就被定成不可操控（`playerControllable = false`，逻辑处理器也控制不了它）。
所以这里的设计是：**玩家只决定"何时开火"，落点由卫星自己挑** ——
取射程内最近的敌方建筑。

这不是偷懒，而是让"打哪里"变成**轨道位置的自然结果**：想让离子炮轰某个基地，就得先把卫星送到它上空，
而 LEO 卫星在持续扫描移动 —— 于是"什么时候按下去"成了一个真正需要判断的决策（要等它飞过目标上空）。
如果想在地图上直接点坐标，那等于把卫星变成遥控炮台，与第一阶段的定位冲突。

## 3. 目标与伤害

| 项 | 值 | 说明 |
|---|---|---|
| 落点选择 | 星下点覆盖内**最近的敌方建筑** | 覆盖半径按轨道算（LEO 40 格 @250×250 图，见 `SatelliteManager.coverageRadius`） |
| 中心伤害 | **3000** | 对建筑 |
| 伤害半径 | **8 格** | 按距离**线性衰减**：中心满伤，边缘趋零 |
| 打击对象 | **只打建筑** | 不伤单位、不伤友军、不碰 derelict |
| 冷却 | **60 秒**（`COOLDOWN_TICKS`） | 充能完毕才能再打 |

"按距离衰减"是有意的：落点由卫星位置决定、不会精确命中，如果用"半径内全额伤害"，
一次落点偏一点就等于白打；线性衰减让**靠近中心的建筑吃满伤害、边缘的挨一点**，偏移变成程度问题而不是成败问题。

## 4. 冷却为什么不落存档

`readyAt` 按 `unitId` 记在内存里，读档后**视为已就绪**（`SatelliteManager.reset()` 里清空）。

这样最不容易出岔子：读档时序、名册重建、unitId 复用都不影响它，也不需要在存档块里再加字段
（存档块每加一个字段都要动 revision，而名册那套的读写对称性是有历史教训的）。
代价只有一个：存档前刚好打完一炮，可以在读档后立刻再打一次 —— 可接受。

## 5. 网络

照 `sat-launch` 的既有模式做，不引入新范式：

| 方向 | 包 | 内容 |
|---|---|---|
| 客机 → 主机 | `sat-ion` | `tileX,tileY|unitId`（只传控制台坐标与目标卫星；**落点不传**，由服务器自己挑） |
| 主机 → 请求者 | `sat-ion-result` | 结果码，或 `fail` / `disabled` / `busy` |

服务端处理器与 `sat-launch` 同级校验：包格式 → 坐标解析 → 控制台是否存在 → 队伍匹配 → `enabled` →
限流（`lastIonRequest`，0.5 秒），且**每条失败路径都回包**（否则请求方 UI 会一直等）。
伤害只在权威端结算；特效是世界层的，两端各自播放不冲突。

## 6. 平衡：它和反制端互为代价

| LOIC 一侧 | 量 |
|---|---|
| 生产 | 硅 8000 · 钍 3000 · 塑钢 2000 · 巨浪合金 2000（+ 冷冻液 2000） |
| 生产耗时 | **120 秒**（信号卫星的两倍） |
| 发射 | 轨道燃油（LEO 1000）+ 10000 缓冲电力 |
| 一次打击 | 3000 中心伤害 / 8 格，60 秒一次 |
| 生存性 | **400 血，被反卫星拦截塔两发击落**，且 LEO 锁定难度 ×1.0（最好打） |

也就是说：LOIC 便宜不了、打得也慢，而且它是**最容易被反制**的那一档轨道。
反过来，它逼着对手在基地里养定位器与拦截塔、并为此烧电 —— 这正是第二阶段想要的循环：

```
LOIC 威胁地面  →  地面建定位器 + 拦截塔  →  拦截塔威胁卫星（包括 LOIC 与对方的信号卫星）
```

## 7. 常量速查（`IonStrike`）

| 常量 | 值 |
|---|---|
| `COOLDOWN_TICKS` | 3600（= 60 秒） |
| `DAMAGE` | 3000（中心值，线性衰减） |
| `RADIUS_TILES` | 8 |
| 结果码 | `RESULT_OK` / `RESULT_COOLDOWN` / `RESULT_NO_TARGET` |
