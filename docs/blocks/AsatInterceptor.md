# 反卫星拦截塔（ASAT Interceptor）

> **它自己看不见卫星**——目标来自[卫星定位器](SatelliteLocator.md)共享的情报，按队伍自动连接。
> 先读那一篇会更容易理解本文的平衡部分。

## 1. 一句话

2×2 炮塔：打击 **80 格**内的敌方在轨卫星，两发击落（每发 200 伤害），
每发从电网电池扣 40000 电力，开火前需要 1~6 秒锁定（用时取决于所在位置的信号可用度）。

## 2. 为什么是炮塔，却不开子弹

它继承 Mindustry 的 `Turret`：炮管转向、装填条、射界、开火前炮口对准、悬停面板的炮塔统计、
逻辑处理器控制——炮塔该有的都有。但开火**不创建子弹**：卫星单位 `hittable = false` / `targetable = false`
（见 `src/silicon/content/SatelliteUnits.java`），引擎的索敌与所有常规伤害路径对它们失明，子弹会直接穿透。

这是**有意**的：卫星不能被普通炮塔顺手打下来，否则任何覆盖敌基地的卫星都活不过一分钟。
代价是击落必须由 scripted 伤害（`unit.damage()`）完成，血量 400 就是"拦截成本"。

为此覆写了三个方法，原因都写在代码注释里：

| 覆写 | 为什么 |
|---|---|
| `findTarget()` | 目标来自 `SatelliteIntel` 情报（且引擎索敌本就看不到卫星） |
| `validateTarget()` | 基类默认走 `Units.invalidateTarget`，对卫星一律判"失效"——不覆写的话，刚拿到的目标会被立刻清掉 |
| `shoot(BulletType)` | 不发子弹，扣电 + 结算伤害 |

## 3. 四道门（缺一道就打不出去）

| 门 | 条件 | 缺了会怎样 |
|---|---|---|
| **情报** | 本队至少一座[定位器](SatelliteLocator.md)在工作（3 秒内刷新过） | 没有目标来源，炮塔空转（面板显示"无定位情报"） |
| **射程** | 目标在 80 格内 | 情报里有目标但超出射程，继续等它飞近 |
| **锁定** | 持续瞄准 1~6 秒 | 装填不推进，炮口压不下来 |
| **电力** | 电池里 ≥ 40000 | 待机等电池攒够（不空放，面板红字提示） |

> **沙盒自测放宽**：沙盒模式下这座炮塔也会把**己方**卫星当目标（判据与"测试卫星仅沙盒可用"一致），
> 否则单机里没有第二个队，四道门无从验证。正式模式只打敌方。

## 4. 参数

| 项 | 值 | 说明 |
|---|---|---|
| 射程 | **80 格** | 与定位器的全图探测配合：探测管"看得见"，射程管"够不够得着" |
| 目标来源 | 本队定位器情报 | **自动连接**，玩家无需配对 |
| 射速 | **3 秒 / 发**（`reload = 180`） | 两发 6 秒击落 |
| 每发伤害 | **200** | 400 血 = 两发 |
| 每发电力 | **40000** | 从电网**电池**扣；击落一颗 = **8 万电力** |
| 锁定时间 | **1 秒 ~ 6 秒** | `lockTimeMin = 60` / `lockTimeMax = 360`，随可用度插值 |
| 可用度参考 | `qualityRef = 40` | 可用度 ≥ 40 即按最快锁定 |
| 常驻耗电 | 600/秒 | 待机也在烧电 |
| 建造成本 | 铜 500 · 铅 350 · 硅 450 · 钛 250 · 钍 150 · 塑钢 120 · 巨浪合金 80 | 血量 1200、护甲 6 |
| 预热 / 射界 | `minWarmup = 0.75`、`shootCone = 8°` | 开火前炮口必须基本对准，掠过的卫星不会一进射程就挨打 |

## 5. 面板（保留，但只读）

塔的配置面板保留下来，内容全部是状态、没有任何需要配对的东西：

- **定位情报**：本队当前可见的目标数（0 时提示"本队需要一座工作中的卫星定位器"）；
- **当前锁定用时**：实时反映所在位置的信号可用度；
- **电量**：够不够打下一发（不足时红字）。

## 6. 可用度 → 锁定时间

```
锁定时间 = lockTimeMin + (lockTimeMax - lockTimeMin) × (1 − 可用度归一化)
```

可用度取本塔所在位置 **5 信道的最高可用度**（`SignalChannel.usableAll(…, scopeCode = null)`）——
**与 H 覆盖、频谱面板完全同一个实现**。塔不绑定任何编码：信号编码是信号源的事。

推论：

- 塔建在信号好的地方（信号源/中继器旁）锁定快；荒郊锁定慢，卫星可能已经飞走；
- 敌方可以用**信号干扰器**压制该区域的可用度，让拦截塔锁定变慢甚至锁不上；
- 自己的卫星覆盖也能贡献可用度——"用自己的卫星给拦截塔供信号"是可行的建筑学。

## 7. 平衡：为什么拦截必须这么贵

卫星一侧的投入：

| 卫星一侧 | 量 |
|---|---|
| 发射中枢 | 铜 5000 · 硅 5000 · 塑钢 1250 · 巨浪合金 1250 |
| 生产 | 5000 电力/秒 × 60 秒 = **30 万电力** |
| 发射 | 轨道燃油（LEO 1000 ~ SSO 8000）+ 10000 缓冲电力 |

拦截一侧要付的代价：

| 拦截一侧 | 量 | 作用 |
|---|---|---|
| 每发电费 | 40000 × 2 发 = **8 万电力** | 与发射一颗卫星的电费同量级 |
| 常驻耗电 | 塔 600/秒 + **定位器 2000/秒** | 长期成本：一座定位器给全队供目标，但它很能吃电 |
| 定位器成本 | 铜 800 · 铅 600 · 硅 700 · 钛 450 · 钍 250 · 塑钢 150 · 中空玻璃 200 | 全图探测，一座即可，但门槛拉到中后期 |
| 锁定 1~6 秒 | 由信号可用度决定 | 信号差的区域打了折扣，逼玩家经营信号基建 |
| 预热 + 射界 | `minWarmup = 0.75`、`shootCone = 8°` | 掠过的卫星不会一进射程就挨打 |

**净效果**：击落一颗卫星的代价约在对方发射成本的 1/4 ~ 1/3，而且必须先建立**定位设施 + 信号覆盖 + 电力储备**
三件基建。卫星被打下来不再是免费的事，第二阶段的循环（发射贵 → 覆盖 → 拦截更贵 → 重发或护网）才成立。

可调旋钮，优先级从高到低：

1. `powerPerShot`（每发电费）与 `damagePerShot`（击落需要几发）；
2. 定位器耗电与建造成本（全图探测有多贵）；
3. `qualityRef` / `lockTimeMin` / `lockTimeMax`（信号依赖的强度，想弱化就调小 qualityRef）。
