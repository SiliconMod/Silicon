# ItemTransferHub 检查清单（每轮结束后执行）

> 覆盖中枢全部已实现行为。任何一项失败即阻断"完成"结论。

## A. 逻辑正确性

### A1. 连接与放置
- [ ] 放置中枢：范围内（20格，**整体占位判定**——大建筑边缘入圈即可）未被服务的工厂/仓库/核心自动连入
- [ ] 核心旁容器（邻接核心的 StorageBlock）**不出现**在可连列表
- [ ] 已被其它中枢服务的建筑**不重复连接**（单一归属：认领即从原枢整体抢回，非满员时为「移动归属」）
- [ ] **满连接的中枢**手动单击同网/他网建筑一律不动（容量闸门先于归属裁决，防剥离成孤儿链接）
- [ ] **满员回退**：建造完成事件就近接入时跳过满员枢、自动落到范围内更近次序的有空位枢（预览同口径）
- [ ] 中枢↔中枢互联不受同网排除限制
- [ ] 长按拖线：拖动路径实时显示淡蓝灰虚线预览；松手后按 Point2[] 配置批量建链
- [ ] 双击自身：无链→全连；有链→清空
- [ ] **放置侧预览**：放置任意可连建筑时，范围内最近的中枢以实线激光连向幽灵 + 蓝框 + 该枢范围虚线圈；无覆盖时不标记

### A2. 拉取（工厂/炮台供料）
- [ ] 消费者排序：**炮台(0) > 工厂(1)**；仓储不参与拉取
- [ ] 工厂含 GenericCrafter / MineConverter / Drill / ItemTurret / **UnitFactory / Reconstructor**
- [ ] 同级按缺口比例降序（最饿先吃）
- [ ] 多源料工厂：同帧连续补多种输入（不提前 break）
- [ ] 供源三级：①仓库 ②核心 ③矿机/工厂**产出物**（静态 `consumesItem` 判定）
- [ ] **绝不抽用工厂/消费者的输入原料**——无论其槽位是否已满；无兜底第四级
- [ ] 不自拉：supplier != consumer 全程过滤

### A3. 推送（溢出回流，只面向存储）
- [ ] 触发阈值：矿机/工厂任一输出 ≥ `surplusPushAt`(0.75)；仓储 ≥90%
- [ ] 核心未满即推：`findNearestCore` 内含 acceptItem 动态校验；75% 阈值用 `getMaximumAccepted`（动态实际容量）
- [ ] 输入料保护：配方输入料按 `block.consumesItem` **静态判定**不外运——满仓时 acceptItem 变假不得触发外运（防乒乓）
- [ ] 推送不分发消费者：工厂补料一律由拉取侧消耗预算执行
- [ ] 核心满 / 拒收 / 无核 → 跨全网 BFS 找最近仓库兜底；**排除推送源自身**（防自投自收）
- [ ] 调度顺序：拉取 → 推送；两者由 `timer(0,10)` 节流至 6Hz

### A4. 电力硬门控与计费口径
- [ ] 单价：物品每经过一个中枢，**该枢自身**消耗 10 电力、经手件数 +moved
- [ ] 发起枢只计自己的一跳；远端经手枢经 powerConsumedNext/transferCountNext 延迟一帧并入
- [ ] 计费写入平滑缓冲：瞬时请求 = 最近 SMOOTH_TICKS(30) 帧均值，调度先于求值（守恒：每笔费用恰好摊入 10 帧）
- [ ] **电力不足完全停止**：status < POWER_OK(0.999) → 停转 + 60t 冷却；冷却结束先「探测」（真实请求、零搬运），
      请求被足额交付才恢复——无源电网永不空转
- [ ] 路径过滤：BFS 种子/扩展、bfsPath 中继、directTransfer/forceTransferToStorage 端点全部经 `relayable` 校验
- [ ] 停止态帧首折叠照常且随后清零——禁用期不累积、恢复无尖峰；统计窗口推入零桶自然衰减，显示不瞬间清零

### A5. 统计口径一致性
- [ ] 单价：物品每经过一个中枢消耗 10 电力；**电力消耗按秒计算**（60 tick 滑动窗口）
- [ ] **运输速率为 10 秒滑动窗口**（600 tick，含路过中转件数），每 10 tick 刷新
- [ ] 稳态流量下 耗电 ≈ 10 × 速率（镜像测试场景3/4 固化）；突发段两口径独立反映
- [ ] Power Cost 与 Rate 同刻度刷新（每 10 tick）；停止态统计随各自窗口自然衰减

## B. 边界与防护

| 场景 | 预期 |
|---|---|
| 供源中途被拆 | directTransfer 二次 isValid 校验拦截，下tick重试 |
| 收方满 | consumerSpace≤0 → moved=0 → false |
| 旧存档 items 数组短于当前物品表 | item.id >= length 跳过（防 IndexOutOfBounds）|
| 同名 mod 目录+jar 并存 | 加载冲突 → 只保留一种形态 |
| 核心旁容器 | shouldConnect=false，永不入网 |
| 断电/欠压恢复 | 冷却 60t + 探测验证后恢复；*Next 每帧并入并清空，无尖峰；无源电网探测永不通过 |
| 欠压中枢横在网络中间 | BFS 路径与端点 relayable 过滤：流量绕行或不可达，不经过无电枢 |
| 存档读档 | 链接保留（v1 序列化）；加载期不误删未就绪邻居；旧构建存档（revision<1）安全跳过 |
| 白名单外建筑（传送带等）已连的旧存档链接 | 加载后被拓扑刷新自动剔除，连接数回收 |

## C. 视觉

| 元素 | 规格 |
|---|---|
| 常驻连线绘制方式 | **全局覆盖层**：`Trigger.postDraw`（一帧最终 flush 之后）一次性遍历 allHubs 统一绘制，固定层级 `Layer.plans+3` 并立即 `Draw.flush()` 落屏——画布最后一笔，位于一切世界几何之上；**不可用 drawOver**（v159 反编译：v8 方块延迟渲染，drawOver 在 blocks.drawBlocks() 之前触发，其提交会被随后的方块缓存绘制覆盖——实测常驻连线全体不可见）；带视口裁剪 |
| 常驻连线 Hub↔Hub | **粉色 `hubLinkColor=#ff88dd`** 电力激光（laser 贴图，lineColorFor 统一） |
| 常驻连线 Hub→建筑 | 物流色 `linkColor=Pal.items` 电力激光（同一透明度设置） |
| 放置预览连线 | 仅画「实际会放下」的连接，颜色与放置结果一致（中枢间粉、其余物流色） |
| **放置侧连接预览** | 放置非中枢可连建筑时：范围内**有空位的最近中枢**→幽灵实线激光 + 幽灵蓝框 + 中枢范围虚线圈（`Layer.overlayUI`，postDraw 覆盖层绘制）；锚点与原版 `InputHandler.tileX/tileY` 同款——鼠标世界坐标先减 `block.offset` 再取整（偶数方块半格修正）；满员回退与事件同口径（见 A1）；全部满员/无覆盖→不标记 |
| **满员回退就近接入** | 建造完成事件：最近可连枢普通配额已满 → 继续向更远的范围内枢寻找空位（中枢间目标无上限不受限）；放置预览同口径；自动连接/双击全连天然回退 |
| 预览/单击三色标记 | **已/将直连=蓝** Pal.place；**网络内未直连=紫** Pal.reactorPurple（预览时=即将连入的网络）；**可新建（网络外）=绿** Pal.heal——预览与单击同口径 |
| 复制配置预览 | **钩子期解析线段 + `Trigger.postDraw` 统一渲染**——只有原版输入钩子能取到同批计划上下文，但输入阶段提交的精灵会被其后的方块缓存绘制覆盖（v8 延迟渲染），故解析与渲染分离：drawPlanConfig/drawPlanConfigTop 只产出线段 {x1,y1,x2,y2,粉色?}，postDraw 在最终 flush 之后按 `Layer.overlayUI`(120) 一次画完；只画【计划↔计划】、距离校验防莫名连线、兄弟中枢粉/其它物流色；调试日志标注「延迟至 postDraw」 |
| 配置持久化 | `saveConfig=false`（电力节点同款）：放置计划不携带历史配置——杜绝旧 Point2[] 粘到后续放置产生莫名虚线；复制一律走原理图序列化或 F 键拾取；placeEnded 清空 lastConfig（一次性消费） |
| 后建建筑补连 | 配置应用时目标未建成（含建造中脚手架 ConstructBuild）→ 偏移进 pendingLinks，updateTile 每 10t 重试补连（建成即接上/被占用即放弃/普通满员保留等空位）；600 秒未出现才过期清理；会话内有效不入存档 |
| 中枢间连接独立计数 | **hubLinks 独立列表：无上限、双向对称、粉色状态条**（bar.silicon-hub-links）；不占用普通连接 20 上限；存档格式 v2（revision≥2 才读 hubLinks 段，v1 存档兼容按空处理） |
| 放置连接顺序 | **复制放置：普通建筑拓扑保持复制原模式（不补连、不占配额），但仍自动连接范围内全部中枢**（粉色骨架、无上限、双向对称、距离就近，`autoConnectNearbyHubs`）；无配置的新枢才用剩余容量像电力节点一样补连周围建筑 |
| 连接单一归属 | 普通目标任一时刻只被一个中枢服务：认领路径（Point2[] 复制配置 / Integer 单击·双击自动连·挂起补连）统一经 `stealFromOtherHubs` 从其它全部中枢的 links/hubLinks/pendingLinks 抢回；**容量闸门先于归属裁决**——满连接时点击一律不动（防抢回后无空位入列、把目标剥离成孤儿链接）；中枢↔中枢粉色连接不受此约束 |
| 范围圈 | drawPlace: Pal.placing 圆；drawSelect: Pal.accent 虚线圈 |
| 透明度 | 「中枢连线透明度」设置（规划虚线走 Renderer.laserOpacity） |

## D. 性能红线

- [ ] BFS 复用池（bfsQueue/bfsDists/bfsVisited）每次用前 bfsInit() 清空
- [ ] 批量直转单次最多 10 件；chargeBatch 整批只跑一次 bfsPath（禁止逐件重算）
- [ ] buildingTree.intersect 替代双层 for 扫描（放置预览/自动连接）
- [ ] 无逐帧 new Seq 分配在热路径（consumers 序列允许，BFS 池必须复用）

## E. 回归锚点（改动后必测）

1. 单工厂+仓库：缺料被补、满仓被排空至核心
2. 双同类工厂+单一矿机：两厂轮流获得补给（缺口比均衡）
3. 炮台+工厂争抢同物品：炮台先得到弹药
4. 跨枢传输（A→B→C）：**每个枢纽的耗电 ≈ 10 × 各自经手速率**，中转枢 B 的传输速率有读数
5. 断电：全部停转；来电：恢复
6. 核心对应物品全满：溢出流向仓库（含仓库连在其它中枢上的布局）
7. 拆除中间中枢：两端各自 updateTopology 剔除陈旧链，网络分裂正常
8. 重构工厂接中枢：原料自动补入
9. 传送带/路由器靠近中枢：配置模式不出现绿色可连框
10. 工厂持续生产时耗电栏数值合理（6Hz 节流后无虚高）
11. 存档→读档：全部连线保留
12. 三色标记：单击配置蓝/紫/绿与放置预览一致；跨枢链 A—B—C 单击 A 时 B、C 均显示紫色（不漏判中枢）
13. 中枢↔中枢连线为粉色，中枢→建筑为物流色（常驻/预览/复制虚线三处一致）
14. F 键拾取已连中枢→异地放下：悬停时即见连接虚线（幽灵之下、电力线之上），放置后链接按新位置范围重建（相对坐标 + linkValid 现场校验）
