# 信号系统模型(a0.13.0.0 · SINR 比值制)

> 适用版本:feat/satellite-v2 `b7af036` 起。旧版(a0.12.x)线性制描述已废弃,见文末差异表。

## 1. 实体与数据流

```
信号源 SignalSource(信道 1~5, 编码 4 字符)
   ├─ 覆盖半径 15 格内按归一化高斯广播原始强度(中心 15)
信号中继器 SignalRelay(绑定编码 → 转发同信道信号,15 格,级联同源链)
信号干扰器 SignalJammer(信道 1~5 或全频,同模型衰减的干扰功率)
卫星(真实单位,固化 编码+信道,覆盖圆内定值原始强度)
   ↓ 全部汇入
SignalChannel.effectiveAll(队伍, 点位)  ←— 唯一权威计算(绑定/激活/绘制共用)
   ↓
每信道: { 有效强度 eff, 最强来源 src, 干扰分母 I }
```

## 2. 强度模型(SINR 比值制)

**原始强度**(距离衰减,信号源/中继器/干扰器共用;**对数距离衰减**,0~99 标度):

```
raw(d) = MAX · ( 1 − ln(1 + d/σ) / ln(1 + R/σ) ),  MAX = 99, R = 15 格, σ = 3 格
```

| d(格) | 0 | 1 | 2 | 3 | 5 | 7.5 | 10 | 12 | 13.5 | 15 |
|---|---|---|---|---|---|---|---|---|---|---|
| raw | 99 | 83 | 71 | 61 | 45 | 30 | 18 | 10 | 5 | **0** |

中心满值、**R 处精确归零**(与旧高斯模型一样没有边缘悬崖),形状是"近场衰减快、远场衰减慢"的
对数距离损耗(log-distance path loss);`σ`({@link LOG_SIGMA})越大核心区越平缓。

**有效强度**:

```
I   = 底噪(3.3) + 同信道异源功率和(CCI) + 邻信道泄漏(ACI) + 干扰器功率
SINR = best / I
q   = clamp((SINR − 1) / (SINR_REF − 1), 0, 1),  SINR_REF = 3.5
eff = best × q
```

> 底噪与转发阈值都取了「标度上限 / 30」（旧 15 标度下的 0.5），所以把标度从 15 换成 99 只是
> 数字更细（0~99 整数、显示更平滑），**模型相对行为不变**。

| SINR | 状态 |
|------|------|
| ≤ 1(功率压不过底噪+干扰) | **无信号**(物理可检测的唯一定义;`eff > 0 ⟺ best > I`) |
| 1 → 3.5 | 质量线性 0 → 满 |
| ≥ 3.5 | 满质量(功率全额) |

**设计语义**:干扰压的是**信噪比**,不是从幅度扣功率——强信号天然抗弱干扰(99 强度源遇 13 强度干扰仍满质量;线性制下会被扣到 86),弱信号被任何干扰压死。

### 卫星层(同口径)

覆盖圆内单星原始强度:LEO 9.9 / MEO 8.58 / GEO 7.26 / SSO 9.9 = 旧 15 标度值 ×6.6(固化信道受干扰;信道 -1 不受)。

```
单星有效 e = raw × sinrQuality(raw, 3.3 + 该信道干扰)
叠星(同编码): √(Σeᵢ²)   ← 非相干功率合成,与层间合成同一个 √(Σ·²);N 颗同强度 = e·√N
```

> 「该信道干扰」与地面层**同一实现**(`SignalChannel#jammerAt` = 干扰器功率求和 + 邻信道泄漏),
> 只是本层只查卫星固化信道这一条——不存在"地面求和 / 卫星取最强"的分叉。

净空单星:LEO 7.92 / MEO 5.49 / GEO 3.48——**首星即过中继器激活阈值(3.3)**;叠星按 √N 提升抗干扰裕度
(LEO 有效值:1 星 7.92 / 2 星 11.20 / 3 星 13.72 / 4 星 15.84 / 10 星 25.05;线性叠加 10 星会是 79.2)。
> 注:旧的 `max + ln(1+Σ)` 不是线性尺度函数,换标度后数值不可直接比较(新标度下它会给出 10 星 12.20,
> 比 RSS 更保守)——比较只在同一标度内做(旧标度:对数 3.67 vs RSS 3.79 vs 线性 12.0)。

**为什么用 √(Σeᵢ²) 而不是对数/线性**:

1. 层间合成本来就是 `√(g² + s²)`——叠星用同一个运算后,「先叠星再叠地面」与「把卫星和地面源一起丢进
   √(Σ·²)」结果完全一致(可结合),不再有两套叠加语义;
2. 多颗卫星是彼此独立的**非相干发射源**:功率(幅值平方)相加、幅值按平方根合成;线性叠加等于把 N 颗
   当成一台 N 倍功率的发射机(失真),对数叠加则是在强项上再套一层非线性压缩(缺少物理依据);
3. 尺度自洽:N 颗同强度 = `e·√N`(数量翻 4 倍强度才翻倍),单星语义完全不变(首星阈值不变),
   边际递减但永不"白送"。

## 3. 合成

- **按编码聚合(显示端与判定端同口径)**:H 覆盖与频谱的"可用强度"永远只算**一个编码**——
  - 有"当前查看的编码"时(鼠标悬停或配置面板打开的建筑:源=自身编码、中继=绑定编码、控制台=所选编码)→ 只算该编码;
  - 自动模式(没悬停/没开面板,或检测器这种无编码设备)→ 每格取**最强的那一个编码**(先看地面最强身份,无地面信号才退到最强卫星编码),**不跨编码求和**。
  这样格子上的数字就等于某个中继绑定该编码时真正能拿到的强度;叠加多个不同编码的卫星不会虚高。
- **卫星 × 地面:RSS 功率合成** `total = √(g² + s²)`(同一编码内);卫星对已有地面覆盖的区域是**真实增益**,不再是取 max 的替补;着色归贡献较大一方。
- 绑定判定(`inSignalRange`)是布尔量:任一层可达即可,**无需合成**。
- **中继级联零衰减、卫星硬边覆盖圆(GEO 全图依赖)、非相干功率合成叠星 √(Σeᵢ²)**为锁定设计,不改动。
- **干扰可断地面链路**:中继转发与建筑绑定都按 SINR(见 §4),干扰器/同信道异编码源压到阈值以下即断链;
  同一个压制也会让卫星发射的 1:1 配对判定失败(需要干扰器覆盖到中枢/控制台所在点)。

## 4. 阈值体系(判定端与显示端同口径)

| 判定 | 阈值 | 说明 |
|------|------|------|
| 建筑绑定 | eff > 0 | ⟺ 功率 > 底噪+干扰(SINR > 1);**地面与卫星都按 SINR** |
| 中继器激活/转发 | eff > 3.3 | **同一阈值两条链路**:地面 = `SignalChannel.groundEffAt`(SINR),卫星 = `satelliteStrengthAt`(0~99 标度下 = 上限/30) |
| 上行门控 | hasLiveSource | 编码的地面源全灭 → 卫星停止广播(删源即断链) |
| 绑定自动失效 | hasLiveSource = false | 绑定的编码在本队**已无任何存活信号源**时,控制台与中继器**自动清除绑定**(每 tick,权威端判定后经 tileConfig 下发);判定只看"编码是否还存在"——源仍在但断电/超距/被干扰时保留绑定,由状态行红字提示 |
| 1:1 配对 | inGroundSignalRange | 只算地面层,且按 SINR(eff > 0)——干扰同样会让配对判定失败 |

### 4.1 实时性

- 中继器**每 tick** 重算能否转发(`SignalRelay.updateActive`),干扰器开关、信号源断电/禁用、绑定变更、
  级联上下游变化都在同一 tick 生效;配置面板与悬停信息里的状态行实时显示
  `转发中/信号不足/无电/已关闭/未绑定 · 入站 地面 X / 卫星 Y(阈值 3.3)`。
- 远处空闲中继走"廉价前置"(只判本编码是否有发射机覆盖本点),不跑完整 SINR 批算。
- 级联不再需要几何距离特判:已激活的同编码中继器本身就是发射机,自然进入下一跳的信号项。
- **有效半径**:15 格是原始(几何)覆盖半径;净空单源的实际可转发半径约 12.8 格(按
  `raw·sinrQuality(raw, NOISE_FLOOR=3.3) > 3.3` 解出 d ≈ 12.8,对数衰减下),
  有干扰/异编码同信道源时更小。放置预览的圆仍画 15 格,以覆盖显示/频谱数值为准。

## 5. 频谱面板(信号源/中继器配置界面 + 信号检测器)

`SignalSpectrum`:本点 5 条信道 × {信道 | 占用(全队源/中继数 + 干扰器数) | 干扰 I−底噪 | 可用度条}。
当前信道行高亮。5 tick(约 12 Hz)节流重算。是 SINR 制的**对策入口**:看哪条信道干净 → 切信道规避。

> **H 覆盖与频谱是同一个函数**(`SignalChannel.usableAll`):两边都输出"每信道地面 SINR ⊕ 同编码卫星
> 非相干功率合成"的可用度,H 上显示的就是这五行里最高的那一行——不会出现两处数字对不上的情况。

- **聚合范围行**(标题下的浅灰小字,与覆盖层同口径):信号源面板 = 自身编码;中继器面板 = 绑定编码(清除绑定时为全局);信号检测器 = 全局(各信道取最强编码)。
  "可用度"列 = 该范围内单一编码的地面强度与**同编码**卫星 RSS 合成值。
- **占用列是信道拥挤度**(含所有编码与其他队伍的干扰器),与按编码的可用度列口径不同——看到"占用高但我的可用度满"是正常现象(那是别人的信号/干扰不在我的信道上)。

## 6. 与旧版(a0.12.x 线性制)差异

| 场景 | 线性制 | SINR 制 |
|------|--------|---------|
| 有效强度 | `max(0, best − (N0+CCI+ACI+干扰))` | `best × q(SINR)` |
| 边缘覆盖 | 0.66 悬崖归零 | 平滑精确归零 |
| 强信号 vs 小干扰 | 被等量扣减 | 满质量(SINR ≥ 3.5) |
| 卫星层 | 逐星扣干扰 → 叠星 → 末尾扣底噪 | 逐星 SINR 折算 → 叠星(底噪在质量因子内) |
| 覆盖显示 | max(地面, 卫星) | RSS 功率合成 |
